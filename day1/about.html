About QuickNotes

QuickNotes is a simple web app for capturing short notes the moment you think of them. It is made for anyone who wants to jot something down without opening a heavy note-taking tool.

How to use QuickNotes

  1. Open QuickNotes in your browser.
  2. Type your note into the text box.
  3. Press the Add Note button to save it to your list.

Features

  • Fast, distraction-free note entry
  • A simple list of all your notes
  • Works in any modern browser

Keyboard shortcuts

Shortcut Action
Ctrl + Enter Save the current note
Ctrl + N Start a new note
